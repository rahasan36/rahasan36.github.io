# Travel photos

Drop trip photos in this folder. Naming convention: `tripname-NN.jpg` 
(e.g., `joshua-tree-01.jpg`, `joshua-tree-02.jpg`, ...).

Image guidelines:
- JPG or WebP, 1600px on the long edge is plenty (file size under ~400 KB)
- Compress before uploading — try squoosh.app for free in-browser compression
- Each photo loads lazily (loading="lazy") so a long page doesn't slow the site

To add a new trip, copy an existing <article class="trip"> block in
travel.html, change the metadata, swap the image src paths to your new files,
and commit.
